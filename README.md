# 🚗 Smart Garage Management System

A Smart Garage Management System developed using Arduino IDE and Arduino hardware components to improve parking organization, security, and automation using IoT concepts.

## 📌 Project Objective

This project solves the problems of traditional garages such as:

* Lack of organization
* Weak security
* Manual operation and high employee cost

The system provides a smarter and more efficient parking management solution using electronic components and automation technologies.

---

# ✨ Features

* Automatic garage gate control
* Detects available parking spaces
* Counts entered vehicles automatically
* Displays parking information on LCD
* More secure and organized system
* Reduces human effort and operational costs
* Uses IoT concepts for smart automation

---

# 🛠️ Hardware Components

* Arduino Uno
* White Breadboard
* IR Sensor
* Ultrasonic Sensor (HC-SR04)
* Servo Motor
* LCD 16x2
* Potentiometer
* Jumpers
* Resistors

---

# 📡 Sensors Used

* Ultrasonic Sensor
* IR Sensor

---

# 💻 Software Used

* Arduino IDE

---

# ⚙️ How The System Works

1. The car approaches the garage gate.
2. The ultrasonic sensor detects the vehicle.
3. The system checks if parking spaces are available.
4. If space is available, the servo motor opens the gate automatically.
5. If the garage is full, the gate remains closed.
6. The IR sensor counts the number of entered cars.
7. The LCD displays the number of vehicles and garage status.

---

# 🚀 Installation & Setup

1. Install Arduino IDE.
2. Connect all hardware components correctly.
3. Upload the Arduino code to Arduino Uno.
4. Power the circuit and test the system.
